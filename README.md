# Petrification（石化）

把世界「定格」下来——**生物变雕像，建筑变模型**。

一个 Minecraft 26.2（Forge 65.1.0）模组，玩家使用六种材质的石化药水，将生物、玩家与方块转化为材质化的实体雕像；并通过结构核心把整座建筑压缩为可携带的微缩模型，随时还原如初。

- 适配版本：Minecraft 26.2 + Forge 65.1.0
- 运行环境：Java 25
- 作者：Xiong & Qianwen
- 许可证：[LGPL-3.0](LICENSE)

## 功能特点

### 生物 / 玩家石化
- 支持 6 种材质：**石 / 铁 / 铜 / 金 / 钻石 / 下界合金**
- 雕像由方块实体渲染器绘制原生物模型并按材质着色，外观一眼可辨
- 通过数据组件完整保留实体的 NBT、属性与状态，可随时**还原**回原本的生物
- 雕像可挖掘、放置、合成 / 分解

### 建筑微缩
- 「结构核心（Structure Core）」工具：右键建筑即可自动扫描、识别并压缩
- 生成「微缩建筑方块（Mini Structure Block）」，小巧便携、适合收藏与展示
- 微缩模型以均匀比例渲染内部全部结构，宽扁建筑也不会被拉伸变形
- 再次右键即可整座释放还原：按 tick 分批次放置，水、植物、门、作物、内部陈设与方块实体一概还原，过程中不弹出掉落物

## 软件架构（简要）

| 模块 | 说明 |
|------|------|
| `StatueBlock` / `StatueBlockEntity` | 单一雕像方块，由数据组件驱动材质（不每种材质一个方块），模型由方块实体渲染器绘制 |
| `StatueComponent` | 核心数据组件（38 字段），保留实体全量数据用于还原 |
| `MaterialType` | 六种材质枚举，记录代表方块与着色颜色 |
| `StatueBlockEntityRenderer` | 世界中绘制生物模型并按材质着色 |
| `StructureCoreItem` / `MiniStructureBlock` | 微缩建筑系统：扫描压缩、微缩模型方块 |
| `StructureCompressionHelper` | 建筑检测、调色板压缩、批量还原 |
| `RestorationHandler` | 将雕像还原为实体、铜质涂蜡等 |
| `StructureStatueData` | 压缩建筑数据组件（调色板 + 打包坐标 + 方块实体 NBT） |

## 安装教程

1. 安装 Minecraft 26.2 与 Forge 65.1.0（Java 25 运行环境）。
2. 下载本模组 jar：`Petrification-Xiong&Qianwen-forge-65.1.0-26.2-x.x.x.jar`。
3. 将 jar 放入 `.minecraft/mods` 文件夹。
4. 启动游戏即可在创造模式物品栏（或对应创造标签）找到雕像方块、结构核心等。

## 使用说明

1. **合成材质粉**：龟壳、幻翼膜、硫、潜影壳、青金石、紫水晶可 1:1 合成为对应材质粉。
2. **合成石化 / 还原药水**：用材质粉与对应材料配制六种材质的石化药水；还原粉配方为六种材质粉 + 下界之星（不消耗）+ 红石 + 火药，产出 8 个，可堆叠 64。
3. **石化生物**：手持石化药水右键（或抛投 splash）生物 / 玩家，将其转化为对应材质的雕像。
4. **还原雕像**：手持还原粉右键雕像，恢复为原本的生物并保留数据。
5. **压缩建筑**：手持结构核心右键目标建筑，将其扫描压缩为微缩模型。
6. **释放建筑**：放置微缩建筑方块并再次右键，整座建筑按批次还原回世界。
