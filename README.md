

# Petrification Mod

一个可以让生物和玩家变成石像的 Minecraft 模组。使用药水将生物或玩家石化成雕像，或使用恢复粉末将其恢复原状。

## 功能特性

### 🗿 雕像系统
- **多材质雕像**：支持石头、铁、铜、金、钻石、下界合金六种材质
- **完整保存**：雕像保存实体的所有状态，包括名称、装备、健康值、年龄等
- **自定义外观**：支持保存实体姿势、变异变体、自定义名称等

### ⚗️ 炼金系统
- **石化药水**：投掷药水可石化一定范围内的生物
- **材质药水**：六种材质对应不同效果的石化药水
- **恢复药水**：瞬间恢复雕像为生物

### 🧪 物品
- **恢复粉末**：右键点击雕像可恢复实体
- **合成配方**：支持雕像分解与合成配方

### 🔧 配置选项
- 药水作用范围倍率
- 是否允许创造模式石化
- 是否允许管理员石化
- 雕像方块硬度
- 铜材质氧化率
- 最大氧化程度
- 是否启用氧化
- 雕像渲染距离

### ⚡ 额外功能
- **氧化系统**：铜雕像会随时间氧化变色
- **命令系统**：提供 `/statue give` 和 `/statue setblock` 命令
- **区域效果**：可一次性石化或恢复大范围区域

## 快速开始

1. 将模组放入 `.minecraft/mods` 文件夹
2. 启动游戏
3. 在创造模式物品栏中找到各种材质的石化和恢复药水
4. 对生物使用石化药水，或对雕像使用恢复粉末

## 支持的游戏版本

本模组支持 Minecraft 1.20.x - 1.21.x (Forge)。
