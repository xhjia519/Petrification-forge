# Petrification Mod

## 简介
Petrification Mod 是一个基于 Minecraft Forge 的模组，允许玩家将生物（以及玩家自身）转化为精美的雕像方块。该模组支持多种材质（如石头、铁、铜等），并且能够完整保存实体的外观状态，包括装备、姿势、变异和生命值等信息。玩家还可以通过各种方式将雕像还原为原生物。

## 功能特性
*   **实体石化**：使用特殊药水将范围内的实体变成静态的雕像。
*   **材质系统**：支持 6 种材质：石头、铁、铜、金、钻石、下界合金。
*   **动态氧化**：铜质雕像会随着时间的推移发生氧化变色（可通过配置调整或禁用）。
*   **还原机制**：提供还原药水、还原粉以及蜂蜜块来还原雕像。
*   **指令支持**：管理员可以通过指令生成雕像方块或雕像物品。
*   **高清渲染**：自定义渲染逻辑，精确还原实体的装备、状态和动作。
*   **数据保存**：雕像会保存实体的几乎所有 NBT 数据，包括生物自定义名称、村庄信息等。

## 安装指南
1.  确认已安装 **Minecraft Forge 1.20.1** 版本。
2.  下载模组对应的 JAR 文件。
3.  将下载的 JAR 文件放入游戏目录下的 `mods` 文件夹中。
4.  启动游戏，在菜单中即可看到该模组。

## 配置说明
模组安装后会自动生成 `config/petrification-common.toml` 配置文件，主要包含以下设置：
*   **potionRangeMultiplier**：石化药水的生效范围倍率。
*   **statueBlockHardness**：雕像方块的破坏硬度。
*   **enableOxidation**：是否开启铜质雕像的氧化功能。
*   **oxidationRate**：铜雕像的氧化速度。
*   **allowCreativeMaterialization**：是否允许石化创造模式玩家。
*   **allowOpMaterialization**：是否允许石化管理员（OP）玩家。
*   **statueRenderDistance**：雕像的客户端渲染视距。

## 指令与玩法
### 指令
*   `/statue give <材质> <实体类型>`：生成一个指定材质的雕像物品（可用于放置或手持）。
*   `/statue setblock <x> <y> <z> <材质> <实体类型>`：直接在世界中生成一个雕像方块。

### 物品与效果
*   **石化药水 (Materialization Potions)**：共有 6 种材质对应的立即生效、喷溅和滞留药水。
*   **还原药水 (Restoration Potion)**：可瞬间还原半径内的所有雕像。
*   **还原粉 (Restoration Powder)**：手持并右键点击雕像即可还原。
*   **蜂蜜块 (Honeycomb)**：对铜质雕像使用可为其打蜡，防止氧化。

## 合成配方
模组添加了自定义的合成配方：
*   **雕像分解 (Statue Decompose)**：将放置的雕像方块还原为更基础的物品形式（或者分解为组成它的雕像物品）。
*   **雕像合成 (Statue Compose)**：用于将特定的雕像物品进行合成或处理。
