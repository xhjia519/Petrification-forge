# Petrification Mod

A Minecraft mod that allows mobs and players to turn into stone statues. Use potions to petrify mobs or players into statues, or use restoration powder to restore them to their original state.

## Features

### 🗿 Statue System
- **Multi-material Statues**: Supports six materials: Stone, Iron, Copper, Gold, Diamond, and Netherite.
- **Complete Preservation**: Statues save all entity states, including name, equipment, health, age, etc.
- **Custom Appearance**: Supports saving entity poses, variant types, custom names, etc.

### ⚗️ Alchemy System
- **Petrification Potion**: Throwable potion to petrify mobs within a certain range.
- **Material Potions**: Six materials correspond to petrification potions with different effects.
- **Restoration Potion**: Instantly restores statues back to living entities.

### 🧪 Items
- **Restoration Powder**: Right-click on a statue to restore the entity.
- **Crafting Recipes**: Supports statue disassembly and crafting recipes.

### 🔧 Configuration Options
- Potion effect range multiplier
- Allow petrification in Creative Mode
- Allow Administrator petrification
- Statue block hardness
- Copper material oxidation rate
- Maximum oxidation degree
- Enable oxidation
- Statue render distance

### ⚡ Additional Features
- **Oxidation System**: Copper statues will oxidize and change color over time.
- **Command System**: Provides `/statue give` and `/statue setblock` commands.
- **Area Effect**: Can petrify or restore large areas at once.

## Quick Start

1. Place the mod file into the `.minecraft/mods` folder.
2. Launch the game.
3. Find various material petrification and restoration potions in the Creative Mode inventory.
4. Use the petrification potion on mobs, or use restoration powder on statues.

## Supported Game Versions

This mod supports Minecraft 1.20.x - 1.21.x (Forge).
